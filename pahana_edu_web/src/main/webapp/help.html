System Usage Guidelines for New Users

✅ Step 1: Load a Customer

  • Enter the Customer ID in the input field.
  • Click "Load Customer".
  • If the ID is valid, the customer's name will appear below.
  • If invalid, an error will be shown.

✅ Step 2: Add Items to the Bill

  • Enter the Item ID.
  • Click "Add Item" to include it in the bill.
  • Each item will show:
    • Item name
    • Price
    • Available quantity
    • Quantity input (default is 1)
  • You cannot add items with 0 stock or set quantity above stock.

✅ Step 3: Review Items and Total

  • All items will be listed in a table.
  • You can change quantities (within stock limits).
  • Click "Remove" to delete any item.
  • The Total Bill will update automatically.

✅ Step 4: Save the Bill

  • Once customer and items are set, click "Save Bill".
  • The bill will be saved and redirected to a printable invoice page.

🔁 View a Previous Bill

To view a saved bill, use the link format:

http://localhost:8080/pages/billing/print.html?billId=YOUR_BILL_ID

🔙 Go Back to Home

Use the browser's Back button or a "Back" button on the print page to return.

🛠 Troubleshooting

  • “Customer not found” → Invalid customer ID.
  • “Item not found” → Invalid item ID.
  • “Quantity cannot exceed available stock” → Set a lower quantity.
  • “Item already added” → You cannot add the same item twice.
