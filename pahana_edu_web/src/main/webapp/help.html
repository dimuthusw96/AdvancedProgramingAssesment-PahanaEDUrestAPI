🆘 Help Section

System Usage Guidelines for New Users

✅ Step 1: Log In

  • Go to /login.html.
  • Enter your Username and Password.
  • Click "Login" to access the system.
  • If login fails, check your credentials or contact admin.

✅ Step 2: Manage Customers

  • Navigate to the Customer menu.
  • Options available:
    • Create – Add a new customer with details.
    • View – See all customers.
    • Search – Find customers by ID or name.
    • Update – Modify customer details.
    • Delete – Remove a customer.

✅ Step 3: Manage Items

  • Go to the Item menu.
  • Available actions:
    • Add – Enter Item ID, name, price, and stock quantity.
    • View – List of all items.
    • Update – Edit item details.
    • Delete – Remove items from stock.

✅ Step 4: Create a Bill

  • Go to Billing → Create Bill.
  • Enter Customer ID and click "Load Customer".
  • Invalid ID will show an error.
  • Enter Item ID and click "Add Item":
    • Shows name, price, and stock.
    • Quantity defaults to 1, can be changed within stock limit.
    • Cannot add out-of-stock items or duplicates.
  • Review all items in the table — update quantity or remove items.
  • Total amount updates automatically.
  • Click "Save Bill" to store it in the system.

🔁 Step 5: Reprint/View Previous Bills

  • Go to Billing → Bill Reprint.
  • Enter the Bill ID and click "View".
  • Or open directly via: http://localhost:8080/pages/billing/print.html?billId=YOUR_BILL_ID

🛠 Troubleshooting

  • Customer not found → Check ID or create customer first.
  • Item not found → Verify ID or add the item.
  • Quantity exceeds stock → Reduce quantity.
  • Duplicate item → Already in bill; remove before re-adding.
  • Login issues → Reset password via admin.
